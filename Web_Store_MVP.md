### План реализации: Модуль «Web-витрина (MVP)»

#### 1. Инфраструктура Image Proxy & Caching
**Цель:** Обеспечить быструю и стабильную отдачу изображений из Telegram CDN пользователям.

*   **Endpoint `/media/image/{image_id}`:**
    *   Принимает ID изображения из БД.
    *   **Логика загрузки:** Если файла нет в локальном кэше -> запрашивает `file_id` у Telegram -> скачивает байты -> сохраняет на диск -> отдает пользователю.
    *   **Локальный кэш:** Создать папку `data/media_cache/`. Использовать `image_id` или хеш `file_id` как имя файла.
    *   **Оптимизация:** Установка HTTP-заголовков `Cache-Control: public, max-age=86400` (24 часа), чтобы браузеры не запрашивали картинку повторно.
*   **Зачем:** Прямая загрузка из Telegram для каждого пользователя слишком медленная и быстро исчерпает лимиты Bot API. Локальный кэш делает сайт «летающим».

#### 2. Поисковый движок (Trigram Search)
**Цель:** Реализовать «умный» поиск по 30 000+ товарам, который прощает опечатки.

*   **Настройка PostgreSQL:**
    *   Миграция Alembic для выполнения `CREATE EXTENSION IF NOT EXISTS pg_trgm;`.
    *   Создание GIN-индекса на поле `clean_title` в таблице `albums`.
*   **Логика поиска:**
    *   Использование функции `similarity(clean_title, query)` в SQLAlchemy.
    *   Сортировка результатов по степени совпадения (от более релевантных к менее).
*   **Зачем:** Обычный поиск по подстроке (`LIKE`) бесполезен при таком объеме данных и специфических артикулах.

#### 3. Навигация и Роутинг (FastAPI)
**Цель:** Связать базу данных с пользовательским интерфейсом.

*   **Главная страница (`/`):**
    *   Выборка последних 24 альбомов со статусом `completed`.
    *   Передача списка «Топ-категорий» для карусели.
*   **Страница категории (`/category/{id}`):**
    *   Фильтрация альбомов по `category_id` (через таблицу ассоциаций).
    *   Реализация пагинации (offset/limit) для бесконечного скролла или кнопок страниц.
*   **Страница альбома (`/album/{id}`):**
    *   Загрузка всех связанных объектов `Image`.
    *   Отображение `clean_title`, обложки и всей галереи.
*   **Зачем:** Четкая иерархия URL важна для SEO и удобства навигации.

#### 4. Frontend: Дизайн «Modern Marketplace»
**Цель:** Создать визуально чистый и дорогой интерфейс в стиле Grailed/StockX.

*   **Верстка (Jinja2 + Tailwind CSS):**
    *   **Header:** Минималистичный. Лого по центру. Кнопка «MENU» слева (открывает список брендов). Строка поиска встроена в шапку.
    *   **Product Grid:** Квадратные карточки (`aspect-square`) с `object-fit: cover`. Тонкие границы (1px) и легкие тени.
    *   **Typography:** Использование качественных системных шрифтов (Sans-serif для цен/артикулов, Serif для акцентов).
*   **UX-фишки:**
    *   `loading="lazy"` для всех изображений.
    *   "Skeleton screens" (серые блоки-заглушки) пока картинка подгружается из кэша.

#### 5. Интеграция воронки продаж (Telegram Deep Linking)
**Цель:** Максимально упростить путь от просмотра товара до диалога с менеджером.

*   **Кнопка «Order in Telegram»:**
    *   На странице товара генерируется ссылка: `https://t.me/{MANAGER_USERNAME}?text=Hello! I want to order: {clean_title} %0A Link: {current_url}`.
    *   `MANAGER_USERNAME` берется из `.env`.
*   **Зачем:** Это превращает каталог в инструмент прямой продажи. Менеджер сразу получает всю нужную информацию о товаре.

### Senior Notes для Trae (Технические нюансы):

1.  **Async Database Access:** При рендеринге шаблонов Jinja2 в FastAPI, убедись, что все обращения к БД (особенно к связям Many-to-Many) выполнены через `await` до передачи объекта в шаблон, чтобы избежать `MissingGreenlet` ошибок.
2.  **Memory Management:** При стриминге изображений через Proxy используй `FileResponse` для файлов из кэша — это наиболее эффективный способ отдачи статики в FastAPI.
3.  **Search Performance:** Если поиск по триграммам будет занимать более 200мс, ограничь выборку `LIMIT 100` и добавь минимальный порог схожести (например, `0.3`).
4.  **Error Handling:** Если `TelegramService` возвращает ошибку (например, файл удален), роут `/media/image` должен отдавать стандартный `placeholder.jpg` из папки `static`.
